# Low Footprint Manifesto

[English](README.md)

O custo do desenvolvimento de software caiu, o de memórias RAM não.
A bateria do seu macbook não é infinita, muito menos a do seu celular. Por isso, quanto menor for o uso de memória RAM e mais eficiente for o consumo energético das suas aplicações, melhor.

Bem vindo à era da programação com IA de baixo consumo.

## Princípios

- Não use linguagens de alto nível, como TypeScript, Python etc.
- Economize o máximo possível de memória.
- Tenha o menor impacto possível no gasto energético.
- Assuma que a aplicação vai passar por conexões intermitentes, lentas ou instáveis.
- Meça os resultados continuamente e aprimore ainda mais sem comprometer funcionalidades.
- Prefira Rust ou linguagens nativas, como Swift.
- Seja obcecado por eficiência energética.
- Compare resultados antes e depois.
